# 供应商基础功能：第一版界面设计

- 日期：2026-10-11
- 状态：**设计原型 + 本机真实桌面接入开发版**；不是已完成双平台安装验收的 GUI 发行版。
- 范围：供应商列表、详情、新增、编辑、启用／停用、密钥操作和异常反馈。
- 视觉基线：用户指定的 [shadcn Blocks](https://ui.shadcn.com/blocks)，采用 `sidebar-07` 可折叠侧栏与 inset 内容区；Tailwind v3 / Radix 兼容源码来自官方 v3 同名 Block。
- 基线：[桌面前端技术设计](frontend.md)、[当前供应商 CLI](../cli/commands.md#5-供应商)、`internal/state/types.go`、`internal/client/client.go`、`internal/core/server.go`。
- 源码：[desktop/frontend](../../desktop/frontend/README.md)。桌面接入边界见[供应商接口语义](provider-interface.md)及[桌面运行契约](desktop-runtime.md)。

## 1. 产品边界

本版先把现有供应商配置能力变成清晰的桌面工作流，不重新做业务后端、不默认扩展整个管理产品。图形界面的正式承载仍是 Wails；浏览器仅用于本地设计预览，没有独立 Web 产品或线上部署。正式桌面版须同时满足 Windows／Linux 的[统一启动与生命周期目标](frontend.md#11-已确认的桌面启动与生命周期目标2026-10-11)：双击打开 GUI、自动启动／复用本机核心、关窗不停服；开发版已实现这些宿主机制，Go 真实核心集成已测试，原生两端仍需验收；Mock 模式本身不启动核心。

| 用户操作 | 现有核心／CLI 能力 | 当前界面 |
| --- | --- | --- |
| 查看供应商 | `provider list`，包含 revision、has_secret | 表格、只读详情、名称／地址搜索、启用状态筛选 |
| 新增 | `provider add`，expected revision=0 | 表单默认 Responses、120 秒、并发 4、启用；密钥可选 |
| 编辑 | `provider put`，完整替换、当前 revision | ID 只读，保留所有普通字段，不用默认值覆盖已保存配置 |
| 启用／停用 | 完整 `provider put`，启用状态作为字段 | 详情中的操作；确认目标、revision 和路由影响 |
| 密钥保留／替换／清除 | secret=null／非空字符串／空字符串 | 编辑时三种明确操作；清除须额外确认 |
| 删除、改名 | 无相应管理入口 | 不提供假按钮；明确说明不在范围 |
| 连通性、余额、延迟、模型发现 | 无本版供应商入口 | 不伪造健康值或测试结果 |
| 本机核心启动／复用与显式停服 | 宿主自动协调；CLI `stop --approve` | desktop 模式自动连接就绪后显示供应商页；关窗不停服；停服另行确认 |
| 远程／多实例切换 | 未实现 | 不提供假切换入口；prototype 仅显示模拟、未连接 |

供应商业务继续使用已有 `provider list/add/put`，没有新增一套业务规则。实际新增的 `stop --approve` 及就绪状态／错误分类见[CLI 变更历史](../cli/changes.md)。搜索、筛选、外观属于展示能力；Mock 写入仅改内存，desktop 保存才写本机核心。

## 2. 信息架构与布局

以下为原型布局示意；desktop 模式保留骨架，连接徽标与实例来源改为真实状态，移除原型场景切换。

- 使用 SidebarProvider → Sidebar（collapsible=icon，variant=inset）+ SidebarInset；桌面侧栏 16rem、图标折叠区 3rem（inset 外侧间距另占 1rem），顶部 64px（折叠时 48px），内容内边距 16–24px。<768px 为可关闭的导航抽屉；支持触发器与 Ctrl / Cmd+B。
- 页头唯一主操作“添加供应商”；刷新、编辑用次级或图标按钮。
- 配置计数并入状态筛选，不另造仪表盘摘要带；没有请求量、余额或性能图表。加载／不可用时计数显示 `—`，不当作零配置。
- 表格将供应商名称与 API 根地址合并为双行身份单元；普通单行表格基线仍为 40–44px，本页双行身份行采用约 68px 变体，避免小字号挤压。技术地址等宽，长地址截断，详情内完整换行。
- 桌面宽工作区按需出现 320px 详情侧栏；≤1200px 窗口详情移到列表下方。表格只在自身容器内横向滚动，不扩大整个窗口。
- 编辑使用一个 600px 内的滚动弹窗。风险确认与详情编辑不同时打开，不嵌套弹窗。
- 表单底部操作跟随弹窗内部滚动区域，不依赖固定屏幕高度。小窗口折行，但取消与保存始终可达。

## 3. 视觉与组件

严格使用 `frontend.md` 的 **官方 shadcn Blocks + neutral 主题**。废弃初版 Linear / slate / 靛蓝方向，主操作浅色为黑、深色为白。采用官方侧栏、表格、按钮、输入等源码，业务弹窗基于既有受控 Radix 逻辑适配官方表面风格，允许针对供应商内容适配，不把自行拼装的相似样式称为官方 Block。来源与适配信息记录于原型 [SHADCN_SOURCES.md](../../desktop/frontend/SHADCN_SOURCES.md)，含官方 registry 内容哈希与 MIT 许可。

- 系统字体，不下载在线字体，不调用 CDN；图标统一 Lucide。
- 正文与控件 14px、标题 24px；地址／辅助文字 12px。控件 36–40px；业务图标点击区 36px，导航触发器与抽屉关闭按钮至少 32px。
- 颜色全部用语义 CSS 变量，通过官方源码适配的本地基础组件与 Tailwind v3 使用，不引入第二套 UI 体系。
- 首次跟随系统，可切浅色／深色。唯一持久浏览器偏好为 `anchor.ui.appearance`；配置和秘密不进入 localStorage、sessionStorage、URL 或日志。
- 启用是带文字与图标的绿色状态，停用是中性色；未连核心与警告不是“已连接”的绿色圆点。
- 焦点环独立于普通分隔线。界面支持减少动态效果；加载标识没有无限重试。

当前组件源码由 Anchor 维护；Sidebar／Button／Input／Table／Switch 等使用官方 v3 源码，Dialog／Alert Dialog 基于既有受控 Radix 原语管理焦点与未保存确认，未宣称复制完整官方 Dialog 文件。没有批量安装全部 shadcn 组件，也没有运行组件 CLI 后宣称完成桌面适配。

## 4. 关键工作流

### 4.1 查看与查找

进入供应商页 → 首次加载 → 展示目录或独立错误／空数据状态。点击名称选择详情；列表是唯一已保存实体来源，详情不另查一份配置。搜索名称和地址，筛选启用状态；无匹配结果可清除筛选。过滤掉当前选中对象时详情不继续展示不相关数据。

### 4.2 新增与编辑

新增：输入供应商名称／ID → 主页（可选）→ 请求地址（1..16 个，可增删）→ 超时／并发 → 启用状态 → 提交。名称即核心 ID，不额外虚构 `display_name`。编辑时 ID 不可改，表单草稿与已保存实体分离。

- 供应商不显示、不设置协议；协议在 Key 与模型上配置。新增时不填 Key，保存后在详情添加。
- 地址提示 API 根路径可含 `/v1`，不要带 `/responses`；HTTPS 为常规要求，仅数值回环测试地址允许 HTTP。
- 即时格式反馈遵循当前核心范围；核心仍做最终校验。前端避免 URL 浏览器自动改写的非标准缩写回环地址。
- 提交时冻结重复操作，完整提交普通字段并携带编辑时 revision；不以 `has_secret` 当密钥值。
- 关闭、取消、Escape、点击遮罩：直接丢弃草稿并关闭，不再提示。
- 保存反馈包含供应商和新 revision，并明确**未测试上游连通性**；只有 prototype 模式带“演示”，真实模式不显示模拟成功。

### 4.3 密钥

- 既有密钥不可读，不显示真实值或将 `••••` 回填成待提交的值。
- 保留：secret=null；替换：非空新输入；清除：secret=""，须勾选针对当前供应商的影响确认。
- 新增可不配置密钥，适用于无需认证的回环测试上游。是否需要认证由真实供应商决定，不由本页制造额外业务规则。
- 仅允许显示本次新输入；输入框成功／取消／卸载时清空，提交开始即清空输入。失败不保留密钥供自动重试，需重新输入。Mock 只更新 has_secret，丢弃密钥值。
- 浏览器内字符串不能承诺内存物理擦除；这里保证不持久化、不回显已存密钥、不写入日志和传输以外的数据对象。

### 4.4 启用／停用

选择供应商 → 查看详情 → 点击启用／停用 → 展示目标与 revision、路由影响 → 取消默认获焦 → 明确确认。停用保留配置与密钥，不保证中断在途请求；启用不等于健康。更新复用同一完整替换入口，不造独立业务规则。

## 5. 状态设计与可访问性

| 状态 | 行为 |
| --- | --- |
| 首次加载 | 加载文字和图标；新增／刷新防重复；计数 `—` |
| 空数据 | “添加你的第一个供应商”；不是错误 |
| 正常 | 列表、查询、只读详情、编辑与确认 |
| 无匹配 | “没有匹配的供应商”，可清除筛选 |
| 离线 | 说明实例不可用且不回退目标；禁写；可重读 |
| 未授权 | 说明管理授权不可用，授权交给宿主，不在页面输入令牌 |
| 读取错误 | 不把读失败当成无配置；可重读 |
| revision 冲突 | 页面与表单保留解释；保存禁用；用户选择丢弃草稿重读，再核对编辑 |
| 写入结果未知 | 不显示成功，不自动重试；关闭已清空密钥的表单，锁写直到显式重读核对 |
| 未实现 | 后续导航禁用；不显示假的删除／健康／余额操作 |

所有按钮可键盘操作；弹窗约束焦点、关闭后回到打开它的按钮。提交错误后聚焦首个错误字段，中文输入法组合期间的 Enter 不触发提交。错误与提示靠近有明确标签的字段；状态不只依赖颜色。

## 6. 工程与职责

```text
pages/providers-page.tsx                      # 只装配业务功能
features/providers/provider.model.ts          # DTO、草稿、转换、即时格式校验
features/providers/provider.mock.ts           # 只供原型的类型化内存传输
features/providers/use-provider-controller.ts # 加载／提交／冲突／风险流程
features/providers/*.view.tsx                 # 列表、详情、编辑展示
components/ui + components/shared             # 基础组件与公共状态／确认
desktop/                                     # Go 生成类型、受控传输、会话 hook
app/                                         # 导航、外观、会话装配；没有进程连接策略
```

依赖方向是 View → hook Controller → Model／类型化传输。页面没有直接 HTTP／Wails 请求；没有数据库、CLI 命令拼接、Agent 文件访问、SSH 或任意系统能力。供应商／会话仍通过五个受限业务方法访问现有 Go client；在线更新另增四个本机受限方法（见[在线更新](online-updates.md)），不开放任意系统操作。业务调用保留管理 API 的 Origin 与实例身份防护。

类型来源为 `internal/desktop/contract.go`，生成 TS；Mock 与 Go 测试共享 `desktop/contract/providers.json`。Mock 单测、模拟绑定浏览器测试、Go 宿主→client→真实隔离核心和原生 Wails 是不同层的验证，前三层不能替代最后一层。

## 7. 交付与验收边界

已建立 Wails v2.15.0 宿主，嵌入 desktop 静态资源；供应商读写与密钥三态、revision 冲突、并发打开及真实宿主进程退出后的核心存活均有隔离 Go 集成测试。核心中途断开后卸载供应商状态／秘密草稿；状态轮询不偷偷重启核心。

实际验证见[前端运行说明](../../desktop/frontend/README.md#验证边界)与[桌面开发版构建](../release/desktop.md)。Windows 交叉编译不等于原生窗口测试；安装包轮增加 Ubuntu24.04 受限容器构建、Windows 当前用户安装器和 Linux `.deb`，现有界面、供应商契约保持不变。该轮按用户要求只编译／打包，不做安装或原生验收、不发布、不启用自启动或修改用户真实配置。

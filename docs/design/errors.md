# 核心错误管理与多语言

2026-10-20：当前源码已接入，未打包／未发布。范围为核心网关、管理 API 的显式错误响应，以及协议转换时由 Anchor 生成的流式失败消息。桌面整站语言切换、CLI 语言参数及操作系统错误的全面翻译不属于本轮实现。

## 定义与职责

`internal/apierror/catalog.go` 是核心 API 错误的统一定义入口，每个内部消息 ID 对应 HTTP 状态、稳定错误码和格式参数类型。`locales/en.json` 与 `locales/zh-CN.json` 按消息 ID 集中维护英文和简体中文模板，通过 Go embed 随二进制发布，不需要运行时文件或翻译服务。

业务层调用 `fail(w, apierror.BindingModelDenied)`，不再在各调用点拼接状态码、错误码和英文文案。Agent、Skill、日志查询等错误分类器只选择消息 ID。不同场景可以保留相同的对外错误码，例如 JSON 字段错误与多个 JSON 对象均为 `invalid_json`，但使用不同消息 ID 与模板。内部消息 ID 不新增到响应或历史日志字段中。

JSON 错误响应继续采用 `{ "error": { "code": "…", "message": "…" } }`，message 统一带 `[Anchor] ` 前缀。HTTP 状态、错误码和协议内既有错误结构保持不变；调用方应依赖 code，不匹配 message 判断行为或重试。原来直接返回校验器字符串的供应商／模型配置错误改用对应分类的固定模板，不将任意底层错误作为翻译参数。

## 请求语言

核心读取每次请求的 `Accept-Language`，在鉴权之前确定本次错误语言，支持：

- `en` 及 `en-*` → 英文。
- `zh` 及 `zh-*` → 简体中文 `zh-CN`，目前不提供独立繁体中文译本。
- 按合法 q 权重从高到低选择；相同权重保留头中的先后顺序；`q=0` 不参与选择；通配符 `*` 选择兼容默认英文。
- 无头、没有支持的语言或没有有效偏好时回退英文。无效条目跳过；头超过 1024 字节整体回退英文，只处理前 32 个语言条目。

核心 JSON 错误附带 `Content-Language: en` 或 `zh-CN` 以及 `Vary: Accept-Language`。语言仅保存在本次响应包装中，不修改进程全局语言、配置、上游请求或其他并发请求。

示例：同一条模型范围拒绝请求，默认 message 为 `[Anchor] model is outside the binding route scope`；携带 `Accept-Language: zh-CN` 时为 `[Anchor] 请求的模型不在当前 Agent 绑定的允许范围内。`；两者均返回 HTTP 403 与 `binding_model_denied`。

语言或单条翻译缺失时，渲染层回退英文。未知消息 ID 或格式参数数量／类型错误返回固定 `internal_error`，不输出调用方传入的任意文本。当前模板参数只用于核心控制的限制数值、协议名与固定原因标签，禁止传入凭据、请求内容、原始上游／解析／文件系统错误。

## 流式、日志与现有客户端

协议转换中由 Anchor 生成的失败事件复用同一目录与请求语言，保留 Responses / Chat Completions 的 `upstream_stream_error` 和 Messages 的 `api_error` 结构。SSE 已提交后的错误不会重新设置 HTTP 状态或错误响应头。相同协议透传的上游 SSE 错误保留原文；语言层不翻译或重新标注上游内容。响应包装实现 `Unwrap`，保留 `http.ResponseController` 的流式刷新和写入截止时间能力。

请求与系统日志继续存储稳定错误码、阶段及安全结构字段，不持久保存本次翻译文案，不回填历史日志。语言变化不影响 Token、尝试次数、状态与查询筛选。现有 Go 管理客户端仍只接收受限错误码，桌面桥接继续分类后由界面显示已有文案；本轮没有改变桌面 DTO、CLI 契约或现有界面语言。后续界面翻译应继续根据可信错误身份选择本地文案，不能直接展示任意远程 message。

## 扩展与验证

新增核心 API 错误时，在目录中增加消息 ID 与状态／错误码定义，并补齐两份语言资源，再由业务层引用。新增语言时，在资源目录增加对应文件并登记加载与协商规则。不要在业务文件内新增独立的英文或中文错误响应。

目录测试检查翻译覆盖、参数模板一致性、未知消息与缺失翻译回退。核心测试覆盖鉴权前语言协商、请求间语言隔离、绑定拒绝的错误码与零派发日志，以及上游 SSE 原样交付；协议测试覆盖三种目标协议的本地流式失败消息。所有真实请求测试使用隔离状态与本机模拟上游，不访问真实供应商。

# Skill 中心库与固定版本挂载

- 状态：2026-10-17 源码增量，包含核心、CLI、桌面桥接与页面；未打包、未发布，不代表现有安装版本支持。
- 命令唯一入口：[CLI 大全](../cli/commands.md#14-skill-中心库当前源码未发布)。

## 1. 不迁移现有文件

扫描只读；首次导入复制完整 Skill 文件树到 Anchor 状态目录下的 `skills/library/<skill-id>/vN`，不移动、删除、改写项目或 Agent 原件，也不把原目录替换成软链接。根目录只在明确写操作时初始化。

新 Skill 先创建中心库 v1，再单独选择作用域、版本与目标目录名进行安装。安装仅允许目标不存在；即便已有目录内容完全一致，也必须拒绝覆盖。用户自行移除原件后，仍需显式安装；扫描不自动安装或恢复缺失的挂载。Anchor 不提供“删除任意项目原件”接口。

## 2. 身份、版本、来源、挂载分离

- Skill ID：随机稳定身份；同名来源默认是不同 Skill，不按名称自动合并。CLI 可在第一次导入时用 `--skill` 指定已有身份；已关联来源不允许静默换身份。
- Version：每个 Skill 的不可变 v1、v2…完整文件快照，记录父版本、来源基线、创建时间、来源类型、文件清单与摘要。全树摘要包含相对路径、文件字节哈希、长度及本平台可执行位，而非仅比较 `SKILL.md`。
- Source：原始目录路径与最近一次成功导入的版本号。扫描变化不保存版本；只有用户明确导入／保存才可能产生版本。相同摘要复用已有版本，可能复用历史版本，不承诺每次操作都递增版本号。
- Mount：目标作用域、路径、Skill ID、固定版本和精确软链接目标。不使用可变 `current` 链接；保存新版本不改变任何现有挂载。更新／回滚均针对单个挂载显式确认。

来源以最近导入基线 B、当前来源 S、库最新版 L 判定：

| 条件 | 状态 | 默认行为 |
| --- | --- | --- |
| 未导入 | local | 只读展示，可明确复制导入 |
| S = L | in_sync | 内容一致，导入复用快照 |
| S ≠ B，L = B | source_changed | 待导入变化，不自动版本化 |
| S = B，L ≠ B | library_changed | 库有不同版本，不回写来源 |
| S ≠ B，L ≠ B，S ≠ L | diverged | 双方分歧，明确导入保存来源快照，不自动合并 |

差异按文件列出新增／删除／修改，包含可执行位变化。文本是变更前后并排预览，不是行级合并器；二进制只标记变化。默认来源比较导入基线，也可选库版本比较；库版本默认展示与父版本差异。没有三方合并、分支发布、SemVer 或批量自动升级。

## 3. 发现范围与限制

不是全盘扫描，也不承诺发现所有已安装 Agent 和所有项目：

- 全局：共享 `~/.agents/skills`；有配置目录证据时读取默认及配置的 Codex、Claude Skill 目录，以及已知 Gemini、OpenCode 全局位置。目录证据不等于可执行程序已安装，与模型网关托管登记无关。
- 项目：有界只读 Codex `.codex-global-state.json` 的已保存／排序工作区根，以及用户明确登记的绝对项目路径；读取 `.agents/skills`、`.claude/skills`。
- 不读取聊天正文、凭据或任意 Agent 配置内容；不猜测 Claude 编码项目名，不包含未经核实的 DSH Skill 布局。未知位置可登记项目，未来以适配器增补。
- 外部目录软链接只登记为 `external_link`，不跟随、不导入、不接管。已有 Anchor 挂载单列，原位置缺失／冲突只报告。
- 64 个项目、64 个 Skill、每 Skill 64 个版本、256 个受管挂载、256 个来源关联。单次扫描最多256个新来源，此外保留最多256个历史关联的未扫描条目；某些未扫描关联标记 missing，需检查作用域／扫描警告，不能直接认定原件被删除。
- 每作用域最多256个目录项；每树256个普通文件、512个含目录的条目、8 MiB文件内容；单次扫描哈希读取预算32 MiB，失败树也消耗预算。索引文件最大4 MiB，Skill 客户端响应独立上限16 MiB；写前预留索引空间，超限拒绝。
- 路径使用可移植 ASCII 段：每段1–64字节、相对路径最多512字节、绝对根路径最多1024字节，拒绝遍历、Windows保留名、大小写冲突、内部符号链接、特殊文件、危险所有权／权限、硬链接等。遇到不支持的原件只报告，不修改权限或文件。
- 空目录不进入文件快照；可编辑 UTF-8 文本每文件48 KiB，二进制完整复制但不在线编辑。管理请求仍受128 KiB JSON正文限制，多文件请求还受总正文限制。差异每侧每文件4 KiB、总文本128 KiB，截断显式提示。

## 4. 写入、安全和恢复

统一路径：前端 Model → 受控 Wails Bridge → `internal/client` → 管理 API → `internal/skills.Manager`；CLI 复用同一核心。端点为 GET `/control/v1/skills`、POST `/control/v1/skills/detail`（只读）与 POST `/control/v1/skills/action`。沿用 owner 授权、Origin 防护和实例校验；所有动作需 `approved=true` 和最新 workspace revision，导入另需扫描／详情的来源 hash。远端 Context 的路径属于远端核心主机，非桌面本机。

核心互斥与系统文件锁保护写操作；快照暂存后发布，索引原子替换并同步。加载时校验索引身份、版本、文件摘要、关联、挂载目标与恢复日志；快照被外部篡改时拒绝读取／更新，不尝试覆盖修复。快照文件默认只读，但同账户仍可改权限，不能声称操作系统级不可篡改。

挂载写前保存 intent，更新时隔离旧链接，再只向空位置创建新链接。中断后扫描只提示，下一次明确批准的动作先核对恢复已批准的事务；恢复改变 revision，触发动作需刷新后重新确认。外部替代文件／链接不覆盖，冲突时保留日志及隔离链接；用户应先核对并自行移开冲突项，再刷新与明确操作。不要手动删除日志或把恢复解释为“扫描自动恢复”。尚无单独的恢复取消／孤立快照垃圾回收界面。

解除挂载只移除与记录目标精确匹配的受管链接；已缺失时仅移除记录；外部替代内容拒绝。库删除存在任何挂载记录时拒绝（包括缺失记录，需先解除），删除只移除索引及来源关联，保留磁盘快照作为恢复数据；不触碰原件。没有自动垃圾回收。

Windows 需系统允许软链接（开发者模式或相应权限）；失败报告 `skill_link_unavailable`，不自动退化成复制。Windows 不保留 POSIX 可执行位，摘要使用 false；Linux保留可执行位。跨平台本机原生 GUI／Agent 加载行为未验收，跨编译不能替代原生验证。

## 5. 桌面交互与验证分层

`features/skills/skill.model.ts` 校验规范生成 DTO；`use-skill-controller.ts` 管理读取生命周期、草稿、二次确认、并发写锁和结果未知；`skills.view.tsx` 仅展示中心库／本机来源／挂载。切换设备通过 instance key 卸载并丢弃旧状态；写入期间阻止导航，失败只重读不自动重试。缺少真实绑定／旧核心报错，不回退 Mock。

页面支持创建、文本文件新版本编辑／新增／删除、来源差异和导入、项目登记、固定版本安装、单挂载更新／回滚／解除及库删除。将不同来源明确归入已有 Skill 暂由 CLI `import --skill` 提供，不按同名猜测合并。

共享样例：`desktop/contract/skills.json`。隔离 Go 核心／CLI／桌面桥接测试、前端 Model 测试、浏览器模拟绑定和真实两平台原生验收分别记录；浏览器 Mock 成功不代表已验证真实 Agent 读取软链接。

# 供应商与 Key 分组倍率（2026-10-15，当前源码）

## 口径与设置

**有效相对倍率 = 供应商倍率 × Key 的当前有效分组倍率。**

- 供应商编辑面板新增“供应商倍率”，默认 `1`。它表示充值的实际成本，例如支付1到账2，填写 `0.5`。合法范围 `0.000001..1000`，必须有限。
- CLI 沿用 `provider add/put --cost-multiplier N`；省略时新建默认1、编辑保留原值。API 的 `cost_multiplier=0` 是兼容旧写入方的省略值，不表示免费供应商。
- Key 分组倍率来自平台自动核对该保存 Key 的查询结果，含平台返回的个人覆盖／高峰等有效倍率，不将组名或协议推断成倍率。允许平台报告有效的零倍率。
- 例如供应商0.5、Key A分组2、Key B分组0.8，则有效相对倍率分别为1和0.4；同一 Key 的全部模型复用该 Key 的缓存。修改供应商倍率立即重新计算，不必重新请求平台。
- 旧 `Candidate.Multiplier` / `workspace.models[].multiplier` / `provider model-put --multiplier` 仅为未来模型倍率保留；数据兼容保留，**当前不参与调度**。桌面不再提供手工模型倍率输入。

## 自动缓存与失效

`provider models` 查询目录时逐启用 Key 抓取倍率，普通 `provider effective-rate` 在 `remote-key-id=0` 时核对本地 Key 并写入同一持久缓存。显式远端数字ID可能属于别的 Key，因此只返回观察结果，不污染本地缓存。目录列表本身仍不是持久缓存。

schema8 新增 `key_rate_cache`，按供应商和 Key 隔离。`workspace.keys[]` 返回可空 `rate` 和 `effective_multiplier`；缓存包含 multiplier、group、group_name、basis、observed_at、attempted_at、failure。不含密钥或原始上游正文。缓存写入不递增配置 revision；写入事务核验抓取时的供应商 revision，拒绝配置变更后到达的旧响应。

成功刷新覆盖旧观察；失败刷新保留上次成功的倍率和 observed_at，更新失败原因和 attempted_at。没有成功缓存时保持未知，**不默认为1**。2026-10-20 当前源码新增后台维护：核心启动异步检查全部启用供应商／Key，成功观测满一小时刷新，失败或忙碌一分钟后再尝试；供应商／Key／模型映射变更与平台账户配置保存后异步检查，批量变更合并，未到期不重复查询。单个后台 worker 串行复用 QueryProvider，沿用已存 Key 的身份核对、出站路由、并发限额及最多八秒期限；不发推理测试，不阻塞就绪或保存。核心 Close 先取消并等待后台查询，再关闭出站客户端。observed_at 获取不足三小时的分组值才参与新请求费用估算和相对倍率调度；满三小时、无时间或时间不可解析则 effective_multiplier/group_multiplier 为未知，历史观测及失败原因保留可核对。原有手动刷新仍可用，零倍率同样遵守有效期。平台倍率不是历史账单或美元基础价。

更换请求地址、平台／账户授权身份时清空相应供应商缓存；替换某个 Key 的密钥只清空该 Key。删除 Key 连带删除缓存，供应商改名由外键迁移，复制供应商不复制观察缓存。仅修改供应商倍率、协议或并发配置不丢弃已核对的分组值。升级后旧核心不能打开 schema8，需要一起升级客户端和核心，没有数据库降级入口。

## 路由语义

- `round-robin`：将来源展开为实际的供应商／模型／Key 路由，用有效相对倍率倒数做平滑加权轮询。
- `lowest-price`：按有效相对倍率升序；相同倍率保留来源和 Key 的稳定顺序。不代表美元模型单价。
- `cache-priority`：先采用可用的成功亲和路由，否则采用上述倍率加权。
- 有已知可用路由时，未知倍率只作失败回退；全部未知时等权分发但展示仍为未知。存在零倍率路由时先在这些路由间等权分发，避免除零；其他路由仍可回退。
- `priority` 仍遵循固定候选与供应商 Key 策略，`lowest-latency` 仍按近期成功延迟，不强行改成倍率调度。
- 来源 Key 范围、健康／冷却、并发、禁用与转发前复查继续生效；低倍率不越过安全门禁。倍率或缓存变化会重建权重债务，不要求模型 revision 改变。

## 前后端边界

Go 核心计算最终倍率并负责缓存与路由。桌面 Model 校验返回值，View 只显示供应商倍率、各 Key 分组倍率／相对倍率、缓存时间和失败状态，不自行实现业务计算。内存原型以合成数据模拟缓存，用于交互验证，不代表真实平台或原生安装验收。

指令以[CLI 大全](../cli/commands.md)为准；测试和未验证范围见本轮任务更新记录。

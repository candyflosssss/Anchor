# 日志可选显示内容

2026-10-12 已接入真实日志；2026-10-15 源码将 27 个独立字段归为 12 个可选显示块。指标口径不变，未知保持未知；隐藏显示块只控制展示，后台采集、历史保存、复制与导出不受影响。本次为纯桌面展示调整，无 CLI 或桥接契约变化，未打包发布。

请求日志右上角“显示内容”打开面板，按类别勾选后立即生效。已选显示块可上下移动，决定表格从左到右的顺序；至少保留一块，右侧详情入口始终可用。宽表仅在列表内横向滚动，详情入口固定在右侧；窄窗口的面板改为单列。

## 默认与预设

| 预设 | 显示顺序 |
| --- | --- |
| 常用 / 默认 | 时间、结果与交付、模型、供应商 / Key、耗时与速度、Token 用量 |
| 性能 | 时间、模型、供应商 / Key、请求方式、耗时与速度、Token 用量 |
| 排障 | 时间、结果与交付、请求 ID、供应商 / Key、错误与阶段、尝试次数 |

预设应用后仍可自由勾选和排序，“恢复默认”恢复常用布局。系统日志暂沿用固定字段，不受请求列偏好影响。

## 可选显示块清单

| 分组 | 显示块 | 块内信息与布局 |
| --- | --- | --- |
| 基础信息 | 时间 | 时间主行，相对时间辅行 |
| 基础信息 | 结果与交付 | Anchor 结果与上游 HTTP 并列，失败时保留错误码，生成状态、客户端交付分行；多次尝试加次数提示，HTTP 200 不等于校验成功 |
| 基础信息 | 请求 ID | 请求与系统事件的稳定关联标识 |
| 基础信息 | 来源 | 代理请求或主动推理测试 |
| 模型与路由 | 模型 | 公开模型主行，实际模型、请求思考深度分行，长 ID 可折行 |
| 模型与路由 | 供应商 / Key | 供应商主行，Key 安全标签辅行，不显示密钥本体 |
| 模型与路由 | 请求方式 | 协议路径主行，流式 / 非流式辅行 |
| 模型与路由 | 配置版本 | 请求当时的配置 revision |
| 速度与用量 | 耗时与速度 | 两列两行：总耗时 / 首字、正文 / TPS；固定标签、等宽数值右对齐，总耗时和首字加重 |
| 速度与用量 | Token 用量 | 两列两行：输入 / 输出、缓存命中 / 思考；输入输出加重，底部合计单独一行。缓存和思考不再次累加到合计中，多次尝试标注“已知小计” |
| 结果与诊断 | 尝试次数 | 实际派发次数，允许为零 |

详情侧栏复用全部 12 个显示块，不受列表的隐藏与排序影响；尝试时间线与结构诊断仍保留。表格采用固定列布局，超长值在块内折行而不是撑宽整页；480px 及以下窗口的详情字段改为单列，避免块内数字和 ID 被切碎；块内不新增解释段落或解释性 Tooltip。

显示块注册表位于 `desktop/frontend/src/features/logs/log-columns.model.ts`；Controller 管理偏好和布局，View 按注册表渲染。继续使用 `anchor.ui.logs.columns.v1` 本地偏好键：旧字段 ID 自动映射到对应显示块，按首次出现的位置去重，未知 ID 忽略，空或损坏偏好恢复默认。新选择与排序保存为块 ID；只选择原来的单项会显示其完整归组，不保留块内单字段开关。

## 指标口径与缺失数据

指标来自协议结构事件和上游明确报告的字段，不推测供应商内部时间。

- **首字时间**从根请求开始计时，包含首字之前的路由、重试和等待；首个网络包、角色事件或单独的思考事件不算正文。没有可靠正文事件时间就显示“未知”。
- **TPS**只在流式、完整观测正文生成区间、正文 Token 明确且为正、生成耗时有限且为正时计算。排除思考 Token、首字前等待和重试时间；不直接用“总输出 / 总耗时”。非流式、流式中断、只有思考或区间 / 用量缺失时显示“未知”。
- **思考深度**展示请求设置值，如 low、medium、high；明确未设置时显示“未指定”，没有快照时显示“未知”。不根据模型名或耗时推断，也不表示实际思考时长。
- **用量**缺失不补零。任一次尝试未报告用量时，根请求总量未知；各次确认用量仍见详情。缓存读取通常已包含在输入里，不重复加到总 Token。
- **HTTP / 错误码**没有 HTTP 响应显示“未收到”，没有错误码显示“—”。HTTP 200 可以与 Anchor 校验失败同时存在。没有上游派发的供应商 / Key 显示“未知”；公开模型仍可有解析快照。

共享测试样例包含 HTTP 200 / invalid_response 和成功流式记录：584 ms 首字、1500 ms 完整生成区间、100 个正文 Token，TPS 为 66.7 t/s。样例只用于契约与界面验证，真实页面的数据来自核心。

## 偏好保存与接入边界

本机 `localStorage` 的 `anchor.ui.logs.columns.v1` 只保存已选显示块 ID 和顺序。恢复时迁移旧字段、过滤未知 ID 并去重，空/损坏配置回到默认；保存失败时当前布局仍可用并提示错误。偏好不包含日志、密钥或保留设置。

Model 通过受控桌面桥接访问核心。无绑定/连接时显示错误，不回退 Mock。采集保存覆盖完整安全字段，用户重新勾选后能查看保留历史中的对应值；缺失观测不会补算为零。保留设置与 JSONL 导出在核心执行，不受所选列影响。纯展示偏好不需要 CLI；实际日志管理命令见[最新指令大全](../cli/commands.md)。

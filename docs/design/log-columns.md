# 日志可选显示内容

2026-10-12 已接入真实日志；2026-10-15 源码将 27 个独立字段归为 12 个可选显示块。2026-10-16 新增“发送档位”“加速状态”，2026-10-19 新增“参考费用”，后续拆成原始参考费用、供应商倍率、分组倍率、最终参考费用，现共 18 块。该分组调整不改变指标口径；未知保持未知，隐藏显示块只控制展示，后台采集、历史保存、复制与导出不受影响。布局与列偏好本身为纯桌面展示；费用/倍率快照的核心采集见日志设计。2026-10-15 后续源码修复将界面“首字”改为首次有效输出（正文或工具调用参数），新增可空指标字段；后续源码将 TPS 改为含思考的总输出 Token / 请求总耗时（端到端总 TPS）；本轮口径调整未打包发布。

请求日志右上角“显示内容”打开面板，按类别勾选后立即生效。已选显示块可上下移动，决定表格从左到右的顺序；至少保留一块，右侧详情入口始终可用。宽表仅在列表内横向滚动，详情入口固定在右侧；窄窗口的面板改为单列。“显示内容”使用独立的描边操作按钮，页签的透明底边与负外边距仅作用于日志分类按钮，不覆盖该操作按钮的完整边框和焦点空间。

## 默认与预设

| 预设 | 显示顺序 |
| --- | --- |
| 常用 / 默认 | 时间、结果与交付、模型、供应商 / Key、耗时与速度、Token 用量、原始参考费用、供应商倍率、分组倍率、最终参考费用、发送档位、加速状态 |
| 性能 | 时间、模型、供应商 / Key、请求方式、耗时与速度、Token 用量、原始参考费用、供应商倍率、分组倍率、最终参考费用、发送档位、加速状态 |
| 排障 | 时间、结果与交付、请求 ID、供应商 / Key、错误与阶段、尝试次数 |

预设应用后仍可自由勾选和排序，“恢复默认”恢复常用布局（12 块）。已有自定义布局不强制插入新块（旧参考费用列迁移时按四项展开），可在“显示内容”勾选或恢复默认。系统日志暂沿用固定字段，不受请求列偏好影响。

详情侧栏复用全部 15 个显示块，不受列表的隐藏与排序影响；尝试时间线与结构诊断仍保留。表格采用固定列布局，超长值在块内折行而不是撑宽整页；480px 及以下窗口的详情字段改为单列，避免块内数字和 ID 被切碎；块内不新增解释段落或解释性 Tooltip。

### 分类颜色与信息层级

2026-10-15 当前源码（未发布）：耗时与用量使用紧凑的 2×2 指标小块，每块以图标＋文字标签标识类型，数值置于下方并左对齐。总耗时为蓝灰、首字 / 输入为蓝、输出为橙、缓存命中为绿、思考为紫、总 TPS 为青。颜色只区分类别，不代表延迟或速度的好坏，不引入任意性能阈值。未知项保留“未知”文字，使用中性灰底与常规字重；真实零值仍按所属类别显示。

指标组最大宽度 280px，避免宽屏下标签与数值散开；列表为耗时、用量分别预留 230px、240px 基础列宽。等宽数字保留千分位和单位，不以缩写丢失精度。模型主行与辅助字段分层，已知思考深度采用紫色轻标签，请求协议使用中性标签、流式返回使用青色轻标签。浅色与深色主题分别配置类别色，高对比度模式保留小块轮廓；颜色之外始终保留文字，指标图标为装饰，不重复朗读。详情复用同样的层级和颜色。

显示块注册表位于 `desktop/frontend/src/features/logs/log-columns.model.ts`；Controller 管理偏好和布局，View 按注册表渲染。继续使用 `anchor.ui.logs.columns.v1` 本地偏好键：旧字段 ID 自动映射到对应显示块，按首次出现的位置去重，未知 ID 忽略，空或损坏偏好恢复默认。新选择与排序保存为块 ID；只选择原来的单项会显示其完整归组，不保留块内单字段开关。

## 指标口径与缺失数据

指标来自协议结构事件和上游明确报告的字段，不推测供应商内部时间。

- **首字时间**使用 `metrics.time_to_first_output_ms`，从根请求开始到首次有效输出，包含之前的路由、重试和等待。有效输出是非空正文增量或工具调用参数增量（含 Responses 自定义工具输入）；首个网络包、角色、心跳、工具空壳、空增量及单独的思考事件不计入。未观测到有效输出时显示“未知”。
- **正文首字**独立保存在 `metrics.time_to_first_text_ms`，仍只记录正文，用于正文生成区间，不把工具参数混入正文指标。旧核心和旧历史缺少新指标时，界面可回退到已记录的正文首字；旧的纯工具请求没有时间可回填，仍为未知。新增指标不要求数据库迁移或采集正文/工具参数内容。
- **输出耗时**使用 `metrics.output_generation_ms`，为首次有效输出（正文或工具参数）到协议完成的本机观测区间；成功、completed 且区间为正时设置 `metrics.output_interval_complete`。它可能包含输出之间的思考或等待，不声称是纯解码时间。正文耗时 `generation_ms` 与正文 Token `output_text_tokens` 继续独立保留，不改旧字段语义。
- **总TPS** = 根请求 `output / (elapsed_ms / 1000)`。`output` 已包含思考 Token，不再加减 `metrics.reasoning_tokens`，不使用 `non_reasoning_output_tokens` 或首字后的区间。分母覆盖根请求解析、路由、等待、思考、重试、传输与收尾，衡量端到端总输出效率，不是模型纯解码速度；“输出”区间格独立保留，仅供参考，不是 TPS 分母。
- **可计算条件**：请求结果为 `succeeded`，总输出 Token 有限且非负、总耗时有限且为正。明确零输出显示 `0.0 t/s`；失败、取消、中断、处理中或缺总量/耗时时显示“未知”。不要求流式、首字、完整输出区间或独立思考用量；非流式、纯思考及因输出上限结束但请求成功的记录也可计算。多次尝试仅使用核心确认的根请求总输出，不以最后一次尝试或已知小计替代。
- **旧日志兼容**：已有成功结果、总输出及总耗时即可直接按新口径展示，无需新指标或数据库迁移，也不改写历史记录。缺失输出区间或 reasoning 明细不影响总 TPS；缺失总量不估算、不按字符反推。原有正文/非思考输出区间指标继续按各自语义保留。
- **思考深度**展示请求设置值，如 low、medium、high；明确未设置时显示“未指定”，没有快照时显示“未知”。不根据模型名或耗时推断，也不表示实际思考时长。
- **缓存命中率（纯展示）** = `metrics.cache_read_tokens / input × 100%`，保留一位小数，显示在缓存 Token 数量下方；列表与详情复用。输入采用核心已归一化的总输入（包含缓存读取，Anthropic 还包含缓存写入），不再次把缓存 Token 加入分母。已确认缓存为 0 且输入为正时显示 `0.0%`，完全命中显示 `100.0%`。缺失、非有限或负数、输入为零、缓存大于输入时显示“命中率 未知”，原数量照常展示。根输入可能累加重试，而缓存是最后一次观测，不是跨尝试合计，因此只有确认单次尝试时计算比例；多次尝试或尝试数不明不混用分子分母，仍为未知。该比例不改变核心采集、CLI、复制或 JSONL 导出契约。
- **用量**缺失不补零。任一次尝试未报告用量时，根请求总量未知；各次确认用量仍见详情。缓存读取通常已包含在输入里，不重复加到总 Token。
- **HTTP / 错误码**没有 HTTP 响应显示“未收到”，没有错误码显示“—”。HTTP 200 可以与 Anchor 校验失败同时存在。没有上游派发的供应商 / Key 显示“未知”；公开模型仍可有解析快照。

共享测试样例包含 HTTP 200 / invalid_response 和成功流式记录：584 ms 首字、1500 ms 完整生成区间、120 个总输出 Token（其中思考20），总耗时2100 ms，总TPS 为 57.1 t/s；原非思考输出区间100 Token / 1500 ms 不再用于 TPS。样例只用于契约与界面验证，真实页面的数据来自核心。

## 服务档位的原值与标注

原始 JSON 标量为主行，可识别值附小徽标：`priority/fast` 用青色闪电 Fast，`ultrafast` 用紫色火箭 Ultrafast；形状和文字同时区分，不只依赖颜色。匹配的已知加速报告配勾号；Ultrafast → Fast 配警示并写“仅确认 Fast”，加速请求返回 default/flex/scale 写“未按请求加速”。未知原值显示“未解析／无法确认加速”，缺失、auto 不当作未加速；失败请求也可包含上游已报告的档位，不能混同请求是否成功。不会测量或担保供应商的真实加速或计费。

详情服务档位区另显示入站原值与固定映射策略，复制摘要保留原值。无原值的旧日志只依据已保存的已知观测标签标注；原值安全限制、三态 fast_triggered 与最后候选语义见[采集口径](logging.md#3-采集用量与隐私)。

## 偏好保存与接入边界

本机 `localStorage` 的 `anchor.ui.logs.columns.v2` 只保存已选显示块 ID 和顺序。缺少 v2 时读取 v1，将原 referenceCost 一次迁移为四个费用/倍率块；v2 中手动隐藏项不再自动补回。恢复时迁移旧字段、过滤未知 ID 并去重，空/损坏配置回到默认；保存失败时当前布局仍可用并提示错误。偏好不包含日志、密钥或保留设置。

Model 通过受控桌面桥接访问核心。无绑定/连接时显示错误，不回退 Mock。采集保存覆盖完整安全字段，用户重新勾选后能查看保留历史中的对应值；缺失观测不会补算为零。保留设置与 JSONL 导出在核心执行，不受所选列影响。纯展示偏好不需要 CLI；实际日志管理命令见[最新指令大全](../cli/commands.md)。

## 费用悬浮数据

四个费用/倍率单元格都可悬浮或键盘聚焦，数据 Tooltip 展示输入、输出、缓存读取/写入、思考乘区的数量、USD/百万 Token 单价、相对非缓存输入的单价倍率，以及原始和最终金额。Escape 关闭，点击不误开行详情；同一明细在请求详情保留，触屏可查看详情。使用 Radix 视口碰撞约束、限高滚动和深/浅色语义颜色。具体 JSON、未知及重试汇总语义见[日志设计](logging.md#供应商分组折算与乘区快照2026-10-19-后续源码未打包)。

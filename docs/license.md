## 对应源码与构建

公开候选从干净 Git 提交构建，发行页提供：

- `anchor_<版本>_source.tar.gz`：对应提交的源码、锁文件、发行脚本与文档，以及 `go mod vendor` 导出的实际构建依赖源码。
- `PUBLIC-BUILD.md`（源码包内）：revision、许可证和离线依赖构建命令。Go 编译器不在包内，版本见 `release.json`。
- `LICENSE`、`THIRD_PARTY_NOTICES.txt`、`release.json` 和 `SHA256SUMS`：分别用于正式条款、依赖声明、来源/验收和完整性校验。

需要再分发时，应一并提供这些材料或按许可证安排合规的对应源码获取方式，不能只删掉许可后转卖程序。修改版网络服务的源码入口应由修改版发布者落实；Anchor 不会自动替第三方发布其改动。

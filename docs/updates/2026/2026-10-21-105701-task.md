# 任务更新：新增请求级协议翻译会话并解耦网关数据面

- 时间：2026-10-21T10:57:01+08:00
- 类型：task
- 状态：completed

## 摘要

三协议沿用既有适配器，通过 Session／Attempt 隔离请求基线和候选映射；网关委托请求校验、响应及流式语义，保留调度、网络、重试和持久化；未打包发布或替换运行版本。

## 具体更新

- 新增不可变 Session、独立 Attempt、类型化入口事实与能力校验、普通／流式结果及安全诊断；移出核心的密文语义与工具检查，旧流式 API 委托相同转换核心。
- 网关不再持有 ChatMapping、解析生成内容／结束状态或自行恢复工具身份；每次候选从私有基线编码，历史密文恢复派生独立会话并保持同渠道至多一次和已交付不重放。
- 保留三协议受控原生字段与原生响应字节；原生 Anthropic 保持缺省 4096 max_tokens；内联 additional_tools 同样执行工具能力／托管边界检查；显式非终止或不可表达结束不合成为成功；增加 64 MiB SSE 累计输入限制。
- 原有摘要样式、密文返回投影和 custom grammar 降级策略不变，新增固定降级事实；保留 API 错误码，日志详情／导出追加安全阶段、类别、派发／正文交付事实；列表白名单和历史日志不变。
- 新增九种协议组合、原生保留／跨协议拒绝、并发隔离、未知／零用量、事件／累计／工具／响应上限、取消与阻塞读取清理测试；模拟 HTTP 覆盖候选切换、普通及流式并行 function/custom 两轮闭环、Unicode／转义和日志脱敏。
- 后续复核修正 Anthropic 输出块推进：源项结束后立即关闭当前块并增量交付后续顺序文本，仅并行交错块需要有界等待；测试用分阶段 reader 断言第二块在终止事件前到达且各块只开关一次。
- 同步翻译层契约、既有桥接说明、实施说明和 CLI 日志证据文档；没有新增外部协议、依赖、CLI 命令或 GUI 设置。

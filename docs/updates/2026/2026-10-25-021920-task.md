# 任务更新：修复 Windows 双击应用唤醒已有窗口时的前台权限交接

- 时间：2026-10-25T02:19:20+08:00
- 类型：task
- 状态：completed

## 摘要

新启动进程在发送单实例唤醒请求前，将 Windows 前台激活资格交给现有 GUI 宿主，复用 Wails 显示、恢复与聚焦逻辑；定向测试和交叉编译通过。

## 具体更新

- 受保护的 desktop-host.json 增加 GUI process_id；唤醒前按该 PID 调用 AllowSetForegroundWindow，避免只在后台宿主内请求前台激活。
- 前台资格只交给具体宿主 PID，禁止 ASFW_ANY；缺 PID 的旧版元信息保持原唤醒兼容，Linux 沿用 Wails/GTK。鉴权和单实例锁继续复用，不增加前端绑定或 CLI 契约。
- 增加交接先于唤醒请求、具体 PID、旧格式兼容、无效元信息和宿主 PID 的回归测试；同步前端与桌面运行契约的聚焦语义和 Windows 限制。

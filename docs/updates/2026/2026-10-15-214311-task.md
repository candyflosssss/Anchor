- 核心将记录 revision 冲突、外部改写、不安全配置、默认模型不可用、目录生成失败与未分类操作失败分开；只返回固定安全消息，保留本地 cause 链，不放松写入及条件恢复校验。
- 默认模型不存在由原 404/not_found 改为 409/agent_model_unavailable；绑定不存在仍保持原处理。新增错误码贯穿 Go DTO、生成 TS 与共享 Agent 样例，旧核心的 agent_operation_failed 不再被桌面误报为配置冲突。
- 写失败后保留或展开受影响 Agent 的设置；重读成功才显示已重新读取，重读失败清空过期数据并明确结果未确认，不重放写入。已开启但未 applied 的绑定即使折叠也显示真实状态。
- 补充核心分类/隐私、模型及目录错误链、桌面 allowlist、真实隔离 Bridge/core 外部改写与 revision 区分、前端错误、重读失败及部分启用回归；同步 CLI 帮助、指令大全/历史、前端权威设计与桌面运行时说明。
- 本机 desktop.39 仅运行 version 和 agent discover 只读检查：Codex/DSH 当前 applied；这不能代表 Windows 截图环境成功。未读出秘密、未修改真实 Agent 配置、未调用付费上游、未替换已安装程序、未发布新包。

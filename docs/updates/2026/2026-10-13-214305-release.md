- NewAPI balance-summary 优先使用独立系统访问令牌调用账户接口；没有推理 Key 也可查询；账户授权失败不回退 billing 或 Key 额度，未配置用户令牌时保留既有兼容查询。

- 从干净构建提交 5b1e676c5fbbe66c8802fe8962bfecea8b723664 生成 desktop.27 两平台安装包（linux-amd64/anchor-desktop_0.1.0-dev.desktop.27_amd64.deb、windows-amd64/Anchor-Desktop-0.1.0-dev.desktop.27-windows-amd64-setup.exe），随对应提交源码（vendored Go 依赖）、许可元数据及校验清单共六附件公开；保留 BUILD.json 原始验收状态，发布证据另存 publication。

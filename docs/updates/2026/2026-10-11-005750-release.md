## 摘要

## 具体更新

- 将此前已完成的中文供应商 ID 修订纳入已提交发行源码；本轮主要新增 Windows 原生验收与公开双平台发布流程，没有改动用户真实配置、现有安装或运行服务。
- 标签构建生成两平台程序、归档、AGPL 许可/依赖声明和 vendored 对应源码；Windows runner 检查准确的 EXE/ZIP。finalize-windows 校验同次 run/attempt、版本、revision、输入 manifest 及产物 SHA256 后才完成原生门禁；内部/脏源码/错误证据仍拒绝。
- 新增原生烟测的状态 ACL、独占实例锁、中文供应商、模拟网关、正常退出和状态重开检查；Windows ACL 检查改用 .NET API，不依赖 PowerShell 模块自动发现。
- alpha.5 构建成功但 Windows ACL 检查脚本失败，未公开且未移动旧标签；修正脚本后以新源码 113eb3d626aabe737f404087cdeb57185b13d2b5 构建 alpha.6，通过全部门禁后显式发布。
- 更新 README 的公开 EXE/Linux 下载入口、安装说明、发行流程及 CLI 适用版本。公开发布于北京时间 2026-10-11 00:56:37，保留 prerelease 标记，未宣称代码签名/GUI/自启动。

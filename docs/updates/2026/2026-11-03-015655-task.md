## 摘要

为 Codex 统一设置增加默认开启的自动压缩配置和90%比例，按模型窗口导出阈值，提供 CLI／桌面设置及条件同步恢复。当前源码未打包、未安装到运行实例。

## 具体更新

- 新增 auto_compact=true、compact_percent=90 默认值及兼容旧重试记录的局部保存和 revision 校验。
- 生成目录按已声明的每模型有效 context_window 计算整数阈值；未知窗口不猜测。自动配置时将根级窗口／阈值覆盖保存到 journal 后移除，关闭或恢复时还原原值；后台保留外部编辑。
- CLI 新增 --auto-compact 和 --compact-percent；桌面增加自动配置开关及百分比输入，生成 TypeScript 契约和共享样例同步。
- 补齐计算、溢出边界、开关、旧 journal 迁移、偏好同步、外部冲突和恢复测试；同步 CLI 大全、变更历史及设计文档。

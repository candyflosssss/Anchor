# 任务更新：Key 故障改为临时降权

- 时间：2026-10-19T17:21:52+08:00
- 类型：task
- 状态：completed

## 摘要

自动故障处理改为可配置正权重降权，保留故障 Key 的调度机会，设置菜单只显示字段、控件与简短状态。

## 具体更新

- 401/403、429 与连续失败达到阈值统一临时降权；默认保留10%权重，范围1..100，100%不降权。成功或到期恢复正常权重，删除永久认证排除、硬冷却及独占半开探测；单Key或全部降权仍可调度，手动停用、并发门禁及安全重放规则继续生效。
- Key轮询及模型轮询乘健康因子，有序策略周期性让位并保留fallback，健康因子不修改计费倍率。策略保存重置健康并更新内存策略，避免配置读取失败重新启用自动规则。
- 持久设置新增weight_percent，兼容旧配置与省略该字段的写请求；CLI settings key-cooldown新增--weight-percent，沿用命令名、API路径和旧时长字段名。Go DTO生成TS，共享样例、桌面桥接及隔离CLI用例同步。
- 设置标题与字段改为自动降权，增加权重输入并保留校验／冲突／未知写入锁定；供应商Key状态与摘要显示已降权，模型渠道仍可用，恢复提示及模拟宿主同步。菜单没有解释段落或说明Tooltip。
- 同步CLI最新大全、CLI变更历史、前端及供应商设计文档。只集成本轮改动，保留主工作区的系统代理任务和其他本地文件。未打包、未创建Release或发行标签。

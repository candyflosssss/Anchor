- Wails OnBeforeClose 拦截普通关闭并最小化；ExitDesktop 受控桥接和已批准的更新回调允许真正退出，仅窗口退出不停止核心。
- 更新窗口 Model、hook Controller、桌面适配器与生成契约；应用提供退出界面，更新页说明 dev 渠道与其他窗口退出要求。
- 从干净提交 9b3d4fabd2fb5e5bfe536104a9dc86721cac0f2e 生成 Windows AMD64 和 Ubuntu24.04 AMD64 安装包；包含已完成的 desktop.11 第一优先供应商功能。

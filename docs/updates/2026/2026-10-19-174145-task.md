## 摘要

## 具体更新

- 供应商表单增加请求渠道选择、作用范围提示与详情回显；仅新建／渠道变化时发送 protocol，兼容旧宿主缺少字段时保留现有值。

- 核心显式保存 protocol 时，同一 revision 条件事务更新供应商与已有 default Key 协议，无需重输密钥；省略协议、其他命名 Key、模型覆盖及 Key 启用／健康状态不受渠道修改影响。
- 补充 state、CLI、桌面桥接、模拟上游路径／认证、Model／Mock 与浏览器回归；同步 CLI 帮助、指令大全／历史及前端／接口规范。
- 仅本轮供应商改动进入提交；原工作区代理重构、系统代理文件、node_modules 和 Python 缓存保持不动。

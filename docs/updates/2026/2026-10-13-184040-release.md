# 版本发布：模型来源 Key、分组倍率与调度规则上线 desktop.25 dev

- 时间：2026-10-13T18:40:40+08:00
- 类型：release
- 状态：success

## 摘要

模型映射接入来源 Key、逐 Key 分组倍率、手动排序及五种实际调度规则；从干净提交构建并发布 desktop.25 dev，两平台六附件核对及默认源 Linux 实际更新下载通过。较早的 desktop.24 本地包保留但未发布。

## 具体更新

- 模型映射与账户页展示平台分组倍率。查询按映射来源 Key 串行去重，sub2api优先个人覆盖倍率，NewAPI核对完整Key，未知与不支持保持明确；不会改写路由倍率。
- 候选保存 key_ids，目录导入保留真实来源；请求与重试严格限定范围，引用中的 Key 不能被删除或清空，旧模型空范围继续允许全部启用 Key。state schema5→6顺序迁移，旧二进制拒绝schema6。
- 模型映射显示来源 Key ID 与状态，提供拖动和上移／下移、每模型调度设置、保存／撤销及刷新配置。以 revision 原子保存完整顺序和规则；冲突或未知写入重读，不重放。
- 核心实际支持固定顺序、按路由倍率倒数加权轮询、缓存亲和10分钟、低价按保存路由倍率排序、近期成功首段文本延迟EWMA与30分钟TTL；缓存和延迟观察只在内存中，健康、并发与故障回退继续生效。
- 共享Go DTO、生成TS、Wails桥接、类型化客户端与CLI同步：model routing、model add/put --strategy/--candidate-key、provider model-put --source-key/--all-keys，以及effective-rate自动核对保存的Key。
- 同步CLI当前大全与历史、前端与桌面契约、供应商接口和发布文档；构建源码提交f37d11f、分组倍率提交3f5fe7d已推送main，不纳入并行快速推理测试提交18d1ec0的改动。
- 本轮较早从干净3f5fe7d构建0.1.0-dev.desktop.24，Windows7,805,948字节、Linux5,613,392字节；保留本地未公开，没有清单、上传或Release。
- 从干净f37d11f构建0.1.0-dev.desktop.25，Windows7,829,725字节、Linux5,634,024字节；于北京时间2026-10-13 18:37:11公开dev预发行。同版提供两平台安装包、flat清单、含vendored依赖的对应源码、许可／构建元数据和SHA256SUMS。
- 保留原始SOURCE/BUILD验证事实，另存发布／标签／下载证据；清理本轮两处worktree和guard临时目录，保留dist产物及无关scripts/__pycache__/。

# 版本发布：供应商真实桌面接入与独立核心生命周期（Windows 内部开发构建）

- 时间：2026-10-11T03:42:11+08:00
- 类型：release
- 状态：partial

## 摘要

在既有官方 shadcn Blocks 供应商原型上接通 Wails 受控接口与真实本机核心，补齐自动初始化／启动／核验复用、关窗不停服和显式确认停服；构建 Windows desktop-dev.3。Linux 构建依赖、两端原生验收、安装器和依赖安全门禁未完成，因此标记 partial，不公开发布。

## 具体更新

- 先确立 docs/design/desktop-runtime.md 的 anchor-desktop-v1 语义，再实现 Go DTO → TypeScript 生成、共享供应商样例及漂移检查；前端 skill 和现行设计文档同步真实能力与未验收边界，保留既有 sidebar-07 / neutral 视觉和功能模块 MVC。
- 新增 Wails v2.15.0 宿主、静态资源嵌入与五个受限方法。Go 宿主使用既有 client/core；JS 不操作数据库、文件、shell、管理令牌或任意目标 URL，不放宽认证、Origin 或实例身份校验。
- 宿主在有界协调锁内安全初始化／验证／复用本机核心，按 Linux 独立 session、Windows 隐藏独立进程组启动同一二进制的 --core 模式；窗口关闭只释放宿主会话，不停止核心。凭据缺失、身份错误、端口冲突不覆盖、不强杀。已认证 process_id 只用于核对启动来源，状态轮询同步来源与停服能力。
- 供应商列表、新增／编辑、启用／禁用与密钥保留／替换／清除接入真实桥接，复用 revision 和业务规则；结构化白名单错误、写入结果未知不自动重试、断开清空供应商草稿、缺绑定不回退 Mock。prototype 与 desktop 模式分开，生产构建不包含 Mock 样例／场景入口。
- 核心增加带鉴权、实例身份与严格请求体校验的 POST /control/v1/shutdown，复用正常停服排空／恢复；starting/stopping 拒绝新写入及网关请求，status 反映实际生命周期。新增 anchor [--context NAME] stop --approve（默认不批准），accepted 不表示退出或恢复完成；CLI 帮助、31 条指令大全、变更历史和测试同步。
- 新增受资源保护的 Windows/Linux 开发构建入口、依赖前检、生产资源检查、SHA256SUMS 与 BUILD.json；不覆盖旧产物，不发布、不替换本机安装、不注册系统服务／开机项。登录自启动设置与安装器本轮未实现。
- 本轮共生成三个仅本地 Windows 中间／候选构建：dist/desktop/0.1.0-dev.desktop.1/windows-amd64/（发现 Mock tree-shaking 问题，非候选）；.2 同级目录修复资源隔离（随后被来源／轮询修复替代，非候选）；最终 .3 为当前候选。最终 EXE 17238016 字节，SHA256=84ea3d358cca2e0fbea36ac063d5e3616b9b3c143c847d40d5a2062edec0b54b；元数据明确 dirty=true、native_gui_verified=false、public_release=false。
- 既有未提交 AGENTS.md、初版 UI／Blocks 来源资料、contract-collaboration skill、设计截图及此前更新记录不是本轮新增成果，未撤销或代为提交；公开 alpha.6 CLI 下载和安装链路保持不变。未提交、推送或上传任何发行产物。

## 摘要

新增供应商可选填写 API Key，保存后在同一弹窗获取并导入模型；失败可重试或修改 Key，保留已保存配置。

## 具体更新

- 新增表单提供密码形式的可选 API Key，随供应商原子保存为 default Key；提交即清空输入，留空保持直接创建、不查询目录。
- 复用现有类型化桌面接口、目录及串行导入操作，保存后用返回的 revision 查询模型，支持同页快速或全部导入；目录失败不回滚、不重放创建，可修改配置与 Key 后再次查询。自定义别名仍在供应商详情配置。
- 补充 Key 转换及 UTF-8 长度校验、6 项隔离桌面桥接浏览器测试；同步现有创建断言、恢复按钮定位和保存成功提示范围。同步前端、接口语义与 CLI 功能覆盖说明，CLI 契约未变化。

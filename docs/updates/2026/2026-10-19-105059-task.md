# 任务更新：将模型映射重试迁移为 Codex 统一重试

- 时间：2026-10-19T10:50:59+08:00
- 类型：task
- 状态：completed

## 摘要

移除模型映射的同渠道额外重试，改由 Codex 原生请求与流中断重试统一控制，默认 5 次，并提供设置页与 CLI 持久化入口。

## 具体更新

- 新增当前核心范围的 Codex 重试设置，默认 5、范围 0–10、显式 0 关闭；通过 revision 保护管理写入，同时生成 request_max_retries 和 stream_max_retries，两项各自采用设置上限。
- 设置页遵循 Model / hook Controller / View 与类型化桥接，处理读取、输入校验、保存冲突、未知写入和待同步目标；同步 Go 契约生成结果及共享样例。
- 保存后仅安全同步已启用且已接管的 Codex，保留外部编辑及恢复基线；启动校验纳入重试字段，旧托管配置的 0 可升级到默认 5，不影响其他 Agent 原生配置或重新启用停用目标。配置同步后须重启 Codex / app-server。
- 移除 channel_retries 的模型 DTO、读写契约及界面，旧数据库 JSON 读取时忽略，严格管理写入拒绝该字段；取消网关同渠道重复尝试与退避，保留安全 Key / 候选切换及流输出后不重放。
- 提供 agent codex-settings 查询与 --retries / --revision 保存入口，同步帮助、最新 CLI 大全、变更历史及前后端契约说明。仅提交本任务改动，其他任务工作区改动保留。

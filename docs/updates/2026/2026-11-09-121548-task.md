## 摘要

## 具体更新

- 新增 internal/autostart：仅管理当前用户 HKCU Run 的 AnchorDesktopCore；稳定桌面启动器以绝对数据目录运行 --core，校验已有初始化状态、路径与命令长度，支持显式批准、SHA256 revision、跨数据目录写锁与写后核对。
- 增加本机 autostart status/enable/disable CLI 与无窗口桌面命令识别，拒绝非空 Context；GUI 使用同一后端，选中远程设备仍只操作本机，关闭设置不停止当前核心。
- 设置页新增功能模块 MVC、开关确认、刷新、系统禁用提示、旧宿主与 Linux 不支持状态；冲突和结果未知必须重读，不自动重放。
- Windows 安装器默认不登记；同目录升级保留用户选择，迁移目录转移原启动器已登记的参数，卸载只清理本安装所属登录项；同步 CLI 大全、变更历史、桌面契约和架构说明。
- 只暂存本轮代码和文档；README、CLI 大全及发行说明按 hunk 隔离其他任务的既有改动。推送预检因 main 分叉失败，预检时远端独有35、本地独有27提交，未强推或变基脏工作区。

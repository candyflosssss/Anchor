## 具体更新

- ConnectionProfile 增加可选 selected 布尔字段，Connections 通过独立 desktop_context 返回已选档案；与 active、ready、会话授权区分，不发起 SSH，不改变 CLI Context。同步共享样例并通过 Go 生成 TypeScript。
- 新增设备身份 hook，优先使用已核验会话，启动失败无会话时读取公开已选档案；旧宿主、读取失败和目标不唯一时明确待确认，切换或卸载丢弃迟到结果。
- 断线面板及设备弹层显示名称与 SSH 目标，本机标注此电脑；顶栏不默认冒充本机；设备页显示已选但未连接标记。停止与重启继续使用原已核验 SessionInfo。
- 同步桌面运行契约与前端设计要求；补充 Go 认证失败保留目标且不泄露密码验证、模型可选字段校验及浏览器设备识别回归。本轮没有增加记住密码功能，SSH 密码仍仅本次使用。

- 时间：2026-10-15T15:43:24+08:00
- 类型：task
- 状态：completed

## 摘要

缓存 Token 数量下方显示一位小数命中率，列表与详情复用，保持原数据及导出契约不变。

## 具体更新

- 前端 Model 计算缓存读取 Token / 归一化输入 Token × 100%；不重复累加缓存，0 命中与完全命中分别显示 0.0% 和 100.0%。
- 缺失、非有限、负数、零输入、缓存超出输入时比例未知；根输入可累加重试但缓存是最后观测，仅确认单次尝试时计算，避免跨尝试误配。
- 缓存小块增加命中率辅行，保持数量和配色；补充计算与渲染测试、浅深主题大数值和窄屏详情断言，同步设计文档。

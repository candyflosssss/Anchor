## 摘要

供应商增改查与模型候选引用支持中文；构建本地开发二进制，未替换已安装程序或中断现有核心。

## 具体更新

- 新增独立 ValidProviderID 校验：1..128 Unicode 码点，支持字母（含中文）/十进制数字/._-，首字符须为字母或数字；拒绝非法 UTF-8、路径分隔符、URL 保留字符、空白、控制/格式字符、组合附加符号及 emoji；其他 ID 规则保持不变。
- 同步 Provider.Validate、客户端管理请求与模型候选供应商引用；保持 SQLite schema、JSON 字段、revision 和密钥保留行为。
- 补充边界、持久化、CLI/客户端中文管理与回环模拟网关路由测试；同步帮助、最新指令大全与 CLI 历史。
- 生成 Linux 本地开发程序；未公开发行，未安装覆盖 /home/mosaki/.local/bin/anchor，未停止用户服务、修改真实配置或请求真实上游；公共仓库未自动提交或推送。

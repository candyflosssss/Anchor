- 时间：2026-10-13T12:25:56+08:00
- 类型：task

## 摘要

供应商列表自动显示余额或 Key 额度和识别平台，CLI 与桌面复用核心只读查询。

## 具体更新

- 新增 auto 平台配置、detect-platform 与 balance-summary；公开探测不携带凭据，以接口结构识别 sub2api/NewAPI/OneAPI，探测不保存配置或修改 revision。
- 未指定 Key 时优先已启用 default，再回退首个启用 Key；列表 summary 仅使用推理 Key，不使用保存的用户授权。
- 列表新增余额／额度列和查询提示，区分钱包与 Key 原始额度、未知与错误；两路并发、无轮询，刷新或配置变化丢弃旧响应。
- 账户页默认自动探测；保持识别状态以支持 OneAPI 远端 Key ID 编辑，允许用户具体平台覆盖；健康说明移至悬浮提示。
- 同步 CLI 帮助、指令大全、变更历史、设计契约与共享样例；保持 anchor-desktop-v1 和 DTO 字段。

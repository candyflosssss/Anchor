# 任务更新：统一核心 API 错误定义与中英文翻译

- 时间：2026-10-20T19:19:04+08:00
- 类型：task
- 状态：completed

## 摘要

新增 internal/apierror 错误管理层，迁移核心显式 JSON 错误及协议转换生成的流式失败，支持按请求语言选择英文或简体中文。

## 具体更新

- 集中维护内部消息 ID、HTTP 状态、稳定错误码、参数类型和 en/zh-CN 翻译资源；保留 [Anchor] 前缀。未知消息、参数数量或类型错误回退固定 internal_error；缺少语言或译文回退英文。
- 网关和管理 API 在鉴权前按 Accept-Language 的 q 权重选择语言；JSON 错误返回实际 Content-Language 与 Vary。通过可解包的请求级响应包装传递语言，不改全局状态、上游请求或透传 SSE。
- 迁移 Agent、Skill、日志查询、目录、供应商、路由及网关错误；配置校验不再直接回显底层错误字符串，改用对应分类模板。协议转换自行生成的 SSE 错误复用目录，保持原协议错误结构。
- 补齐翻译覆盖、模板参数、回退、鉴权前协商、请求间隔离、稳定日志错误码、零派发、原样上游 SSE 与三协议转换失败测试；新增错误管理设计文档并同步 API 和日志说明。现有 CLI 命令与桌面 DTO 未变。

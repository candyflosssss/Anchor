# 任务更新：供应商协议按 Key 默认值与实际模型覆盖解析

- 时间：2026-10-11T23:28:31+08:00
- 类型：task
- 状态：completed

## 摘要

协议归属各 API Key，按实际模型名设置独立覆盖；无覆盖动态继承 Key 默认协议，转发、测试与目录认证同步使用所选 Key 设置。

## 具体更新

- 状态 schema3→4 自动迁移全部既存 Key 协议，新增 key_model_protocols；支持协议单独编辑、清除覆盖、revision 冲突回滚和复制/改名/删除级联。
- 网关先选 Key 再解析实际模型覆盖与默认值，路径、认证、JSON/SSE 使用一致协议；换 Key 重试重新解析，推理测试沿用同一规则。
- 目录查询支持选择具体 Key（含停用 Key），返回实际 key_id，认证使用该 Key 默认协议，查询保持只读。
- 桌面 Key 编辑增加默认协议，模型页按 Key 查询并编辑逐模型覆盖；切换 Key 清理目录，已保存覆盖持续可见，留空密钥可只修改协议。
- CLI 增加 provider key-model-protocol、key-put --protocol 和 models --key；共享 Go DTO、生成 TypeScript、Mock、样例、帮助和 CLI/前端设计文档同步。

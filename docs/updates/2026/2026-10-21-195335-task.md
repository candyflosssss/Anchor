# 任务更新：Key 分数冷却、会话保持与模型映射优先级排序

- 时间：2026-10-21T19:53:35+08:00
- 类型：task
- 状态：completed

## 摘要

Key 独立硬冷却到期直接恢复；成功会话保持渠道；模型映射改为可拖动渠道列表并支持倍率和实测首字快速排序。

## 具体更新

- 按时间窗口累计错误分数：401/403=100、429=50、408/网络/5xx=25；达到阈值仅冷却该 Key，默认阈值100、窗口和CD各300秒。成功不清窗口分数、在途结果不延长或解除CD，到期清分直接恢复；兼容迁移旧阈值和设置字段。
- 所有调度策略按调用者/模型/显式会话保持成功渠道；新会话按当前规则选择，当前渠道不可用才fallback。移除提示词推测会话；进程内1024条LRU，重启或淘汰后重选。明确401/403/408/429/5xx可fallback，连接后不确定结果或输出后保留不重放边界，全部不可用返回503及全部渠道不可用。
- 模型映射按模型单列分组，渠道直接显示顺位、状态、倍率、拖动及上下移动。按分组×供应商×隐藏模型倍率快速排序；刷新倍率后显示与排序共用快照。经确认逐渠道实测首字排序，失败/未知后置，可停止；自动和手动排序均保存priority，保留冲突重读、撤销与失败重试。
- ProbeProgress增加可选first_byte_ms，KeyStatus增加可选error_score；同步Go生成TS、共享样例、Mock、CLI新增error-window-seconds、当前指令大全、设计契约和协议skill。

## 摘要

实现 Linux/Windows AMD64 的公开 Release 单文件下载、SHA256 校验及用户级安装；保持状态与 Agent 配置独立。当前尚未推送或公开 Release，未宣称线上可用。

## 具体更新

- 新增 POSIX sh 安装器：默认发现 GitHub 首个最新创建公开 Release（含预发行），支持固定版本/绝对安装目录/显式替换，拒绝不支持平台、歧义标签、异常校验与链接目标；HTTPS-only 下载，独占安装锁，同文件系统原子 no-clobber 安装/替换与暂存清理，默认用户目录，不需 sudo。
- 新增 Windows PowerShell 5.1/7 安装器：AMD64 识别、JSON 版本发现、TLS 1.2/HTTPS 重定向检查、哈希验证、独占自动清理锁和原子替换；修复模拟测试发现的 File.Replace 空字符串路径问题，使用任务暂存目录中的旧文件备份。
- 两平台均不执行下载程序、不启动/停止服务、不初始化/迁移状态、不修改 PATH 持久配置或 Codex；提示当前终端 PATH 设置，已有程序必须显式允许替换，升级须先停服/备份状态。
- 增加隔离离线安装回归，纳入原有发行工具测试发现范围；Actions 增加 Windows 原生安装器测试 job，草稿依赖其成功，未改变触发方式/公开发布权限。该 CI 配置尚未托管执行，不等于 Windows 核心原生验收。
- 同步 README、CLI 最新大全/功能覆盖/外部分发入口历史、发行与随包说明；新增安装文档，明确公开下载源前置条件、平台限制、参数、安全/升级边界。核心仍为 30 个规范命令路径，不增加 anchor install/update。未纳入前一轮单文件打包改动的完成声明。

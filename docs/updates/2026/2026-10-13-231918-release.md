# 版本发布：sub2api 推理 Key 计费倍率修复与 desktop.28 在线更新

- 时间：2026-10-13T23:19:18+08:00
- 类型：release
- 状态：success

## 摘要

以推理 Key 直读 sub2api 当前有效计费倍率，账户及逐 Key 模型来源展示接入；构建并发布0.1.0-dev.desktop.28，默认更新链路实际下载通过。

## 具体更新

- 兼容层新增 /v1/sub2api/billing；读取服务端 effective_rate_multiplier、验证 schema/数值、复用本次探测响应，支持零倍率和部署前缀。
- 无 JWT 的所选 Key 优先直读；仅缺接口404/405或200 HTML回退旧用户授权；失败分类与显式远端Key身份保持。
- 前端支持 key_billing 来源及缺组名展示，授权提示、共享样例、CLI帮助和设计文档同步，查询不改路由倍率。
- 干净构建提交af7359642bcb340c3f723b19ee2b294b496bc3a8；发布0.1.0-dev.desktop.28的Windows/Linux安装包、同版清单、vendored源码、许可元数据及SHA256SUMS六附件。

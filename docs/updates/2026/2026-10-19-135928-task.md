# 任务更新：不可用模型来源折叠后置及删除供应商清理映射

- 时间：2026-10-19T13:59:28+08:00
- 类型：task
- 状态：completed

## 摘要

禁用或暂时不可用的模型、来源与 Key 默认收起并后置；真正删除供应商或 Key 时只清理对应来源，保留其他来源的同名模型。

## 具体更新

- 模型、候选来源及来源 Key 按可用性稳定分组：当前不可用项默认折叠并放到末尾，仍可展开查看原因；恢复启用后刷新回到常规列表。待确认及不完整读取不视为全部不可用，不据此删除配置。
- 纯展示分组不保存路由顺序或增加 revision。含不可用来源时，通过「调整来源顺序」显示完整已存顺序，再支持拖拽、键盘和上下按钮；序号始终对应路由位置。
- 抽取供应商与 Key 共用的事务来源清理函数；删除供应商自动清理其全部候选、Key、策略和价格，仅在候选耗尽时删除公开模型。保留其他供应商与 Key 的同名模型来源、顺序、元数据和价格。
- 保留已启用 Binding 默认模型的最后来源保护，触发时整个删除事务回滚；同步桌面删除确认、引用错误提示、Mock、CLI 帮助与当前文档。
- 新增或更新隔离 SQLite、CLI→管理 API、前端 Model/View 和模拟桌面宿主回归，验证清理边界与折叠、恢复、排序行为。未包含工作区原有余额缓存相关改动。

## 摘要

完成供应商第一优先的 UI、核心与 CLI，必要定向检查通过，并生成 Windows/Linux 本地安装包。当前交付范围为本地开发包，未进行原生安装验收或在线发布。

## 具体更新

- 完成供应商第一优先六组功能的核心、CLI 与桌面 UI：删除/复制/改名、连通测试和模型目录、多 Key、冷却/熔断、Responses/Chat Completions/Anthropic Messages 转换、用量统计。
- 详情顶部统一供应商操作，增加密钥与状态、模型与测试、用量页签；MVC 复用受控 Go 管理接口，真实桌面不回退 Mock；生成契约与共享样例同步。
- SQLite schema 2 自动迁移到3，旧 secret 转为 default Key；引用保护、revision 冲突检查、独立 Key 状态与单次半开探测；客户端取消不计入上游熔断。
- 实现无状态文本/函数工具的 JSON 与 SSE 转换、并行工具 ID/参数保留、完整流结束检查；不支持的内容明确拒绝，不完整流不伪报成功。
- 记录上游尝试用量、失败与耗时，未知用量单列；支持 USD/百万 token 自定义价格与 models.dev 固定公开目录预填，显式保存后生效。
- 同步完整路线图、第一优先设计文档、CLI 大全/变更记录、前端和核心设计、安装与在线更新说明；数据库升级后旧二进制不能打开，未实现降级。
- 从已提交源码 a35ecb6a584c0b01480c5011cf7dabd1c776ac3e（dirty=false）生成 desktop.11 Windows AMD64 安装器和 Ubuntu24.04 AMD64 deb；旧包保留，本轮没有生成/部署在线更新清单或公开发布。

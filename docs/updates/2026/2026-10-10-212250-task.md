## 具体更新

- 为公开模型导入本地、精确版本匹配的完整 Codex 元数据，校验结构、尺寸、枚举与数组；不猜能力或自动获取目录。新增合成测试专用目录，禁止将其作为生产模板。

- 新增 agent set-models 及类型化管理客户端/API，要求显式模型与范围、revision；先安全恢复再条件更新策略，冲突不扩权，token 不旋转，重新 plan/apply。目录为接管快照，刷新后需重启 app-server。
- Responses 同协议透传补充 function/custom namespace 与 client tool_search，拒绝 hosted/server/nested 工具；未实现 Anchor 执行工具或跨协议转换。
- 补充元数据、目录所有权/引用/崩溃边界、迁移/凭据隔离、CLI/API、客户端工具测试；扩展隔离烟测到两个模型与真实 Codex app-server JSON-RPC。帮助、CLI 最新大全/变更历史、README/实施设计说明同步到 30 命令路径。
- 保留上一任务的未提交施工与已有更新记录；仅清理本任务 Python 缓存及 resource-guard 临时目录，没有 commit/push、打包发布或部署。

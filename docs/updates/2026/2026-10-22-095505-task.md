# 任务更新：模型映射按 Key 平铺独立卡片

- 时间：2026-10-22T09:55:05+08:00
- 类型：task
- 状态：completed

## 摘要

模型分组下直接展示每个来源 Key 的独立卡片、状态与倍率，移除渠道卡片内的 Key 折叠层级。

## 具体更新

- 模型标题和工具栏移出外层卡片，每个受限来源 Key 或匿名来源独占响应式网格卡片，显示供应商、Key ID、上游模型、可用状态和倍率；停用、缺失、冷却 Key 直接可见。
- 排序倍率读取当前 Key 而非渠道最低值；倍率刷新只更新计费字段，不覆盖工作台可用性。卡片拖动适配二维网格；同渠道所有 Key 保持整体排序、自动保存及撤销语义。
- 同步模型映射设计说明、已有浏览器断言，并补充多 Key 倍率、来源范围、状态与渠道移动回归；无 CLI、桥接或核心契约变化。

# 版本发布：补齐 Windows 与 Ubuntu 桌面开发安装包（按要求不验收）

- 时间：2026-10-11T04:30:55+08:00
- 类型：release
- 状态：partial

## 摘要

生成 0.1.0-dev.desktop.7 Windows 当前用户安装器与 Ubuntu24.04 AMD64 .deb，沿用现有供应商 GUI 和独立后台核心生命周期；本轮只编译打包，没有安装、启动、测试、原生验收或公开发布。partial 表示公开发行门禁未完成，不表示最终打包命令失败。

## 具体更新

- 先同步本轮安装交付范围，再实现双平台打包入口；保持既有 shadcn Blocks sidebar-07 / neutral UI，不重写供应商业务、桌面 DTO、核心生命周期或 CLI 契约。
- 新增受 resource-guard 管理的 package-desktop.sh / .py 与容器 worker；顺序生成 Windows GUI、Ubuntu24.04 Linux ELF、Debian 包和 NSIS 安装器。发行版本目录不覆盖，生成源码/环境/工具链元数据、依赖通知及 SHA256SUMS。
- Docker 仅安装容器内 GTK3/WebKitGTK4.1/NSIS 开发依赖，宿主系统包不变；显式限制容器内存/Swap/CPU/PID，仓库与 Go/模块缓存只读挂载，以宿主 UID 编译打包，退出清理本轮容器及磁盘临时目录。
- Windows 安装器按当前用户安装，添加开始菜单与可选桌面快捷方式；WebView2 缺失需先同意再运行模块内引导器，失败中止；完成页启动默认不勾选，不注册服务/自启动，不修改 PATH。升级/卸载拒绝占用中的程序，不强杀或删除用户状态。
- Ubuntu24.04 AMD64 .deb 提供应用菜单、程序与图标；从 ELF 提取运行库依赖，没有自动启动/停服脚本或系统服务。升级/卸载前需显式停核心并关闭窗口；不声称支持所有 Linux 发行版。
- 新增基于 Lucide Anchor 的 neutral SVG/PNG/ICO、来源许可及可选生成脚本；宿主本轮仅接入 Linux 图标/ProgramName 并保留原 GPU 策略，已有后台启动/复用逻辑不改动。
- 裸程序 builder 改用 Go DTO 生成器逐字节比对 TS 作为编译前置，不再借打包运行 go test，不静默改生成文件。
- 补充 dlv@1.1.3 与 react-remove-scroll-bar@2.3.8 的通知及来源说明；只排除未安装的可选平台依赖，未知必需通知缺失仍中止。不改前端依赖、不重跑 npm audit、不宣称审计遗留已修复。
- 修复发行版 Go 跨目录符号链接挂载与 Go 许可来源、NSIS 卸载命令引号；NSIS 启用 -WX。保留 .4/.5 INCOMPLETE.json 与 .6 SUPERSEDED.json，三个版本均为非交付中间产物，不覆盖或删除。
- 同步安装说明、前端与运行契约状态、实施/供应商文档、README 与 CLI 覆盖表；明确本轮未验收、Linux 目标范围、历史测试归属与未实现的开机自启动/自动更新，不修改本轮无变化的 CLI 历史。

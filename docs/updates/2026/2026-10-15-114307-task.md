# 任务更新：顶栏改为设备快速切换

- 时间：2026-10-15T11:43:07+08:00
- 类型：task
- 状态：completed

## 摘要

右上角弹层移除实例 ID，提供本机与已保存远程设备快速切换，保留独立生命周期操作区。

## 具体更新

- 新增设备切换 View 与 hook Controller，复用 Connections／UseConnection；打开时刷新设备列表，标记当前设备并提供设备管理入口。
- 密码仅在弹层短暂输入，提交、取消和关闭后清空；连接期间禁用重复切换与生命周期操作，失败保留原会话，关闭弹层不丢弃切换结果。
- 设备连接页按当前会话更新设备标记并共享禁用状态，不因快捷切换重置添加设备表单；实例 ID 仍用于内部校验和停服确认。
- 更新前端设计规范、鉴权错误提示和定向浏览器回归；纯桌面快捷入口，无 CLI 契约变化，未纳入供应商余额／Key 倍率等其他任务改动。

## 摘要

## 具体更新

- 核对固定上游版本的 Web/CLI 与 Electron Desktop 差异：共享 DSH home，但分别使用 profiles/web 与 profiles/desktop。只托管已存在 profile，不创建 Desktop 或修改公共 patch、凭据库、Electron 壳设置。
- 扩展适配器、发现和恢复路径白名单；沿用 schema8 和旧 Web ID/root 键，Desktop 使用独立所有权键，仅允许 Web/Desktop 这一对共根，禁用仍保留所有权。
- 前端固定展示 DSH Web 和 DSH Desktop 独立行，按适配器及规范化路径匹配绑定；更新 CLI 参数帮助、最新指令大全、变更历史和桌面/前端设计。
- 新增同 home 双端生命周期、独立 token、旧 Web 绑定兼容、映射自动同步、CLI、前端 Model 与浏览器开关/同步回归；保留其他任务的模型设置、供应商余额等修改，三个共享文件仅暂存本任务片段。

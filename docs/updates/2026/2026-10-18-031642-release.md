- Windows NSIS 新增目录选择页，保留当前用户默认路径；读取 InstallLocation，支持 /D= 覆盖，拒绝盘符根目录、相对路径与 UNC，共享已安装应用／快捷方式／卸载器使用所选位置。

- 增加9项安装器源码契约回归，修复 SetOutPath 失败后可能继续向旧输出目录写入的问题；同步包内说明、CLI覆盖／安装器参数历史、桌面发行与在线更新说明及README。没有新增 anchor 子命令，CLI 单文件安装脚本 -InstallDir 不变。

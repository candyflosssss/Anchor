## 摘要

供应商存在异常 Key 时在列表和详情显示恢复所有 Key，确认后批量清除当前供应商的 Key 健康限制；同步核心、桌面、CLI 和文档，未打包发布。

## 具体更新

- 新增 key-reset-all 核心动作，一次清除所选供应商当前配置版本全部已存 Key 的失败计数、错误分数、冷却和最近测试，保留密钥、协议、启停状态及 revision，不影响其他供应商；无 Key 时成功空操作。
- 前端以失败计数、错误分数或 degraded/invalid/cooling/half-open 状态判断是否显示恢复所有 Key；列表入口直达 Key 页确认，执行期间防重复提交，成功刷新列表和详情。
- 沿用审批、管理授权、实例身份和 revision 校验；冲突重读后再次确认，写入结果未知时禁止重放并要求显式重读；提示真实上游凭据失效仍需更换。
- 提供 CLI：anchor provider key-reset-all --id ID --revision N --approve，target 必须为空；同步帮助、最新指令大全、变更历史、前端设计和供应商接口契约。
- 在基于 origin/main 的独立工作树集成任务改动，CLI 文档日期冲突保留远端已有 desktop.75 发布说明；原工作区其他文档、记录和未跟踪内容保持原样。

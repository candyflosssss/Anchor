## 摘要

为两个独立 DSH profile 补齐模型映射名称、视觉、上下文及可表示思考档位的共享投影，保留恢复与冲突边界；仅源码改动，未打包发布。

## 具体更新

- 共享转换器从生效 configuration 导出名称、text/image、contextWindow、原值 effort 和显式默认输出；unknown 不猜测，none/default/null、toggle/budget 不伪造档位，原映射不变。
- 默认模型的可表示 default effort 写 agent-default-model.reasoningEffort，始终拥有该字段及其删除；旧 journal 安全扩展所有权，清空设置移除旧字段，恢复保留原用户值。
- 增加双端共 home 隔离、默认切换、旧 journal 升级、幂等、无效元数据拒写、外部修改冲突、条件恢复及管理 API 保存后的双端自动同步测试。
- 同步 CLI 帮助、指令大全、行为变更历史及托管层设计，无新增命令、DTO 或数据库 schema。

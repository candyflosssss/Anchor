# 版本发布：UI SSH 设备连接与 desktop.31 双平台更新

- 时间：2026-10-14T22:38:28+08:00
- 类型：release
- 状态：success

## 摘要

实现 Anchor 内置 SSH 密码／密钥远程实例管理，发布 Windows／Linux dev 在线更新并升级本机 CLI／桌面及运行核心。

## 具体更新

- 侧栏新增“设备连接” MVC 功能，可在本机核心离线时添加远程设备，以 SSH 密码／密钥连接、保存资料、重连、切换与返回本机；仅就绪后切换，失败保留旧会话；按实例隔离工作台状态。
- internal/connection 统一 UI／CLI 连接策略：密钥模式使用受限 OpenSSH stdio 转发，密码模式使用内置 SSH；首次信任显式确认并记住主机密钥，变化拒绝；密码瞬时使用、不持久化，管理凭据保存在受保护 SQLite 表，错误仅返回安全白名单。
- 新增 context add --ssh 系列选项、context bootstrap --control-port --show-once 与全局 --ssh-password-stdin；选定 Context 的业务管理命令复用连接层。bootstrap 初始化／复用账户实例，离线时启动 detached 核心并授予720小时manage权限，不停止或替换其他端口占用者。
- state.db schema6→7 新增私有连接凭据和独立桌面选择，修复合法base64url ID首字符校验；关闭GUI保留远程核心。远程实例活跃时安装桌面更新仍正常停止本机核心；安装交接失败保留远程会话。
- 同步 Go DTO、生成TS、共享连接样例、CLI帮助／大全／变更历史，以及前端／桌面生命周期／SSH连接设计；远端须预装支持bootstrap的新CLI并启用SSH，自动安装尚未实现。
- 功能以1c5c9104e0d232749f1caf122d3b5fd2f4f133de提交并推送main。独立干净源码构建Windows AMD64 NSIS与Ubuntu24.04 AMD64 deb，SOURCE.json dirty=false；包含已提交的模型设置与Claude／DSH托管，保留工作区未提交余额改动。
- 生成flat update-desktop.json、vendored Go对应源码、许可／构建元数据ZIP和SHA256SUMS；草稿六附件验证后公开prerelease并保持非latest，标签指向实际构建revision。
- 本机保留旧CLI／桌面为 ~/.local/bin/anchor.previous-desktop30 与 anchor-desktop.previous-desktop30，正常停服后备份state.db／logs.db／owner.token到 /home/mosaki/.config/anchor/backups/pre-desktop31-20261014-223526；原子替换用户目录程序并重启同名transient核心服务，数据自动迁移到schema7，未新增Agent托管授权。
- 发行文档、README与CLI发布状态同步实际版本；安装包、哈希和发布／下载／本机安装证据保留dist/desktop/0.1.0-dev.desktop.31；任务worktree、临时目录、隔离验证数据与打包容器已清理，保留用户核心服务。

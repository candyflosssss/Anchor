## 摘要

## 具体更新

- Agent/绑定从网关认证上下文采集，不信任客户端伪造标签。项目/会话只接受显式 X-Anchor-Project / X-Anchor-Session 安全标识，不转发上游；不扫描真实客户端配置、提示词或历史，尚未实现客户端自动上报。
- 旧日志及无归属请求保持未识别；可选查询字段区分缺省/空字符串，list/stats/export/suggestions 共用四维条件。增加幂等 SQLite JSON 表达式索引，不重写历史文档。
- 统计分组复用原始累加器，展示请求量、已知 Token、总 TPS、错误率、缓存命中率；响应最多前100组并附总组数，summary/buckets 不受分组截断或分页影响。
- 桌面增加分类汇总、四维历史候选、点击分组下钻、单维清除/重置、详情与安全复制归属。默认不分类，旧核心不支持时明确提示，不回退 Mock。
- 同步 Go/生成 TS 契约、共享样例、CLI 四维筛选和 --group-by、最新指令大全及设计文档。保留且不提交工作区既有的余额功能和其他无关改动。

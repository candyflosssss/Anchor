# 任务更新：模型映射可配置同渠道重试次数

- 时间：2026-10-17T22:24:54+08:00
- 类型：task
- 状态：completed

## 摘要

在模型映射的模型设置中加入独立重试次数，默认额外重试3次，可配置0–10；复用现有模型设置API与CLI并完成隔离验证，未打包发布或替换运行服务。

## 具体更新

- 模型设置新增 channel_retries：默认3次，首次请求不计入，0关闭同渠道额外重试；按供应商、Key、上游模型组成的渠道独立计数，保留其他Key与候选回退、共享超时、取消和无重放边界，退避250ms/500ms后封顶1s。
- 模型映射 → 模型设置 → 重试、上下文与能力新增次数输入及说明，阻止空值、小数、越界和重复保存；保存后重新打开可读取，冲突或结果未知须重新读取，旧核心缺少字段时提示升级而非虚构默认值。
- 沿用revision控制的模型设置写入；旧客户端省略/null保留次数，参考目录操作与configuration替换不清空次数。完整model put settings替换缺字段沿用默认3，省略整个settings保留已有值，无数据库迁移。
- 同步Go/TypeScript桌面契约、共享样例、CLI帮助/最新大全/变更历史与前端和网关设计文档；新增默认值、范围、兼容、持久化、精确尝试次数及活动请求快照测试。
- 仅提交当前任务补丁；保留工作区原有代理、供应商余额、打包脚本等无关改动。本任务没有修改真实Agent配置、请求付费上游、重启服务、构建安装包、打标签或发布Release。

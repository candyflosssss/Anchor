- 时间：2026-10-22T10:28:57+08:00

## 摘要

模型分区继续纵向排列，来源 Key 改用紧凑自适应卡片；整卡可拖动并保存现有渠道优先级。

## 具体更新

- 来源 Key 卡片约260–300px宽，按可用宽度换行；细边框、轻阴影、深色表面和悬停层次突出倍率，分组仍在倍率下方。
- 拖动起点扩展到卡片及供应商文字，达到6px才开始排序；保留实际 Key 的拖动浮层，避免拖动误打开编辑，保留普通点击、Escape、键盘排序和上下移。
- 路由移动仍作用于同一渠道全部 Key，复用现有保存/撤销/冲突处理；没有桥接、后端或 CLI 契约变化。
- 更新模型映射交互设计和浏览器回归场景；不包含并行 Skills 或协议任务的修改。

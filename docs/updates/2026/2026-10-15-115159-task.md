## 摘要

按供应商倍率乘 Key 有效分组倍率计算相对成本，接入持久缓存、逐 Key 调度与桌面/CLI；源码完成，未打包发布。

## 具体更新

- 供应商新增 cost_multiplier，默认1，支持充值1到账2填写0.5；桌面编辑和 CLI --cost-multiplier 同步，旧写入方省略时保留现值。
- schema8 新增供应商/Key 隔离缓存；目录发现及本地 Key 自动核对倍率时保存，失败保留上次成功观察，无缓存明确未知；显式远端数字 ID 不污染本地缓存，身份变更清理缓存并拒绝迟到配置响应。
- 有效相对倍率由核心按供应商倍率×Key缓存倍率计算；成本策略逐Key调度，处理未知和零倍率，继续遵守来源范围、健康及并发门禁；旧模型倍率字段预留但不参与当前路由，桌面撤去手工输入。
- 更新桌面 DTO/生成 TypeScript、共享样例、CLI 大全/变更历史与设计文档；增加倍率校验、缓存持久化、多Key权重、失败保留及桌面交互回归。
- 仅暂存本任务改动；其他任务的余额缓存/UI、旧任务记录和本地产物保留未提交。

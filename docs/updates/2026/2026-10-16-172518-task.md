# 任务更新：日志搜索与筛选支持历史候选

- 时间：2026-10-16T17:25:18+08:00
- 类型：task
- 状态：completed

## 摘要

为日志搜索、供应商、模型、Key、HTTP、错误码和阶段添加来自当前时间范围保留日志的快速候选，并补齐只读管理接口、CLI、契约和文档；本轮仅源码改动，未打包、未安装、未发布在线更新。

## 具体更新

- 新增日志候选查询，固定字段白名单与参数化 SQL，通过只读连接聚合全部时间范围而非当前页；去重、按次数降序排序、字面前缀匹配，默认20项最多100项，最多90天，根请求跨字段同值只计一次。系统日志搜索候选为事件名。
- 新增 POST /control/v1/logs/suggestions，沿用 owner 鉴权与目标实例身份校验、3秒核心超时；Wails LogSuggestions 经类型化 client 访问，5秒宿主超时，Go DTO 生成 TS，共享 JSON 样例。新增 anchor logs suggestions 命令及帮助、当前指令大全、覆盖表和变更历史。
- 前端保持 MVC：独立候选 Controller 仅在输入框聚焦时180ms防抖查询并丢弃过期结果；支持候选次数、鼠标选择、方向键/Enter、Escape/Tab关闭和中文组合输入，旧核心不支持候选时仍可手动筛选，不回退 Mock。时间、结果、来源枚举不变。
- 只修改本任务日志功能与文档；保留工作区既有供应商余额缓存等无关改动，frontend.md 仅纳入日志候选新增段。未修改真实 Agent 配置或访问付费上游。

# 任务更新：可选 SSH 密码系统凭据库存储

- 时间：2026-10-25T22:43:20+08:00
- 类型：task
- 状态：completed

## 摘要

按用户选择增加默认关闭的记住密码及忘记功能；桌面与 CLI 共享系统凭据库，支持已保存密码自动连接，无明文回退；当前源码未打包发布。

## 具体更新

- 新增 connection.Passwords 与可注入 PasswordVault，生产使用固定版本 go-keyring 的 Windows Credential Manager / Linux Secret Service；仅在成功 SSH、固定主机及实例验证、目标 ready 后显式保存，按数据目录、档案、目标、端口、主机密钥与实例绑定 SHA256 引用。SQLite 仅存非秘密引用。
- 桌面契约增加可选 remember_password / password_saved、SessionResult.warning 及 ForgetConnectionPassword；保存失败保留真实在线连接并提示，忘记不关闭当前连接。凭据写入后读取核对、删除后验证不存在，系统提示取消不得误报成功。
- 设备连接页与顶栏密码表单支持默认不记住、显式保存、状态提示及手动覆盖；提交清空输入，旧宿主缺能力字段隐藏记住选项，密码不进入浏览器存储。
- 新增 context password save|status|forget NAME 与帮助、CLI 大全、变更历史；save 强制 stdin 并重新验证目标，status 不读取秘密，桌面启动与 CLI context test、管理、显式 SSH restart/update 可复用已保存密码；本次输入优先且默认不覆盖保存值。
- 新增隔离 SSH/核心/凭据库测试与浏览器回归，覆盖自动连接、忘记、保存失败、失效密码恢复、系统取消、手动输入绕过不可用凭据库和秘密不进入 SQLite/前端 DTO；同步前端与桌面运行契约。
- 保留任务开始时已有的 commands.md 中 desktop.60 段落删除、protocol-recovery-roadmap.md、两份历史任务记录、根 node_modules/ 和 scripts/__pycache__/；不纳入本轮提交。

## 摘要

原生 Responses 明确拒绝历史推理密文时，在安全窗口清理转发副本并同渠道重试一次；日志记录原因、数量和恢复结果，桌面显示中文标记。源码完成，未打包、未替换运行中版本。

## 具体更新

- 识别 invalid_encrypted_content、明确无法验证／调用方不匹配错误；只删除 input 中 reasoning，保留消息、工具调用与结果、compaction 和加密任务，不修改客户端历史。
- HTTP 400/422、非流式 200 JSON 和早期 SSE 错误可恢复；SSE 检查上限 64 KiB／2 秒，非生命周期事件、已输出、无关错误或执行状态不明时不重放。
- 整个入站请求最多一次清理补发，固定供应商／Key／模型／基址，共享超时和并发名额；首次拒绝与补发分记 attempt，缺失用量保持未知，按最终渠道结果更新 Key 健康。
- 根 evidence 记录清理结果、固定原因、移除条目数与重试次数，列表／follow／详情／复制／导出可见；桌面状态列和详情显示恢复成功、失败、取消、进行中或结果未确认。无密文、条目 ID 或正文进入日志。
- 同步 CLI 帮助、最新指令大全、变更历史与前后端设计约束；没有新增手动清理命令或设置。
- 使用任务专属隔离 worktree 验证独立补丁；仅暂存本任务及重叠文件中的本任务 hunk，保留原有代理／升级器等改动。

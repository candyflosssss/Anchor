# 任务更新：内置 mihomo 与供应商/Key 出站代理

- 时间：2026-10-17T00:09:44+08:00
- 类型：task
- 状态：completed

## 摘要

实现 Windows/Linux AMD64 内置 mihomo、独立代理设置页、供应商默认与 Key 覆盖、CLI 和安全出站路由；源码验证完成，未打包发布。

## 具体更新

- 新增独立 egress 模块和 schema9 代理持久化；配置、绑定和运行状态脱敏输出，写入要求批准与 workspace revision；支持继承、强制直连和指定代理。
- 所有供应商推理/流式、模型目录、探测和账户请求按实际 Key 路由；代理连接错误 fail closed，阻止候选重试绕过为直连。
- 内置固定 mihomo v1.19.32，Windows/Linux AMD64 构件校验 SHA256，按需启动回环认证子进程；旧配置排空、崩溃后重建、核心退出回收，支持 Windows Job/Linux parent-death 生命周期。
- 增加前端 MVC 代理页和供应商详情选择器，以及 proxy list/put/delete/bind CLI、类型化 API/桥接、共享契约与文档；不启用 TUN 或系统代理。
- 构建脚本自动准备固定构件并携带完整 GPLv3 许可和来源通知；当前先支持单节点或 Clash YAML 选节点，不含订阅 URL/自动刷新。
- 工作区仍有其他任务修改相同共享文件；本任务未提交或推送，未暂存其他任务内容。
